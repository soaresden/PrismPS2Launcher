RetroArch core override
=======================

Extract a RetroArch PS2 nightly archive here, keeping its own structure:

    Retroarch Extracted Files/cores/picodrive_libretro_ps2.elf
    Retroarch Extracted Files/cores/fceumm_libretro_ps2.elf
    Retroarch Extracted Files/info/picodrive_libretro.info
    ...

Any core present here REPLACES the one bundled under
"System/RetroarchPS2/<System>/cores/". Nothing else to do: no renaming, no
copying into each system folder.

Why an override and not a date comparison
-----------------------------------------
The PS2 Lua API only reports name, size and type for a directory entry, never a
timestamp. The launcher therefore cannot tell which of two files is newer. The
rule is simply: if it is here, it wins. Delete a core from this folder to fall
back to the bundled one.

    fceumm_libretro_ps2.elf         Famicom / NES

    handy_libretro_ps2.elf          Atari Lynx
