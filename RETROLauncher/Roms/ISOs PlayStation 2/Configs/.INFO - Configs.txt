This is where Neutrino's configurations for PlayStation 2 games are stored.
RETROLauncher will search for and load the game configurations from this directory.
Review the Neutrino documentation for more information about the commands.
Neutrino Link: https://github.com/rickgaiser/neutrino

Order of the commands:
* The first line corresponds to the VMC:
	-mc0="directory to your virtual memory"
	Example command for VMC:
		-mc0=mass:/VMC/generic_0.bin

	If VMC is not used, leave this line as "nil"
	Example with VMC disabled:
		nil

* The second line corresponds to the compatibility modes:
	-gc="compatibility modes enabled"
	Example command for compatibility modes:
		-gc=012357

	If you do not enable compatibility modes, leave this line as "nil".
	Example of disabled compatibility modes:
		nil

	Game compatibility modes:
	- 0: IOP: Fast reads (sceCdRead)
	- 1: dummy
	- 2: IOP: Sync reads (sceCdRead)
	- 3: EE : Unhook syscalls
	- 5: IOP: Emulate DVD-DL
	- 7: IOP: Fix game buffer overrun

* The third line corresponds to the GSM configuration:
	-gsm="GSM configuration"
	Example command for GSM:
		-gsm=fp:fp2:2

	If you do not use GSM, leave this line as "nil"
	Example of GSM deactivated.
		nil

	GS video mode / -gsm=x:y:z
	Parameter x = Interlaced field mode
	A full height buffer is used by the game for displaying. Force video output to:
	-      : don't force (default)  (480i/576i)
	- fp   : force progressive scan (480p/576p)
			
	Parameter y = Interlaced frame mode
	A half height buffer is used by the game for displaying. Force video output to:
	-      : don't force (default)  (480i/576i)
	- fp1  : force progressive scan (240p/288p)
	- fp2  : force progressive scan (480p/576p line doubling)

	Parameter z = Compatibility mode
	-      : no compatibility mode (default)
	- 1    : field flipping type 1 (GSM/OPL)
	- 2    : field flipping type 2
	- 3    : field flipping type 3

Supported extensions: .cfg
