Here are the background images for RETROLauncher.
RETROLauncher will search in the root of this directory.

Background Requirements:
	* It must be an image in .png format
	* The image must have a transparency mask otherwise it will not be displayed.
	* The resolution must be 640x480 as maximum, although it can be lower.
	* It is recommended to use 8-bit png images with 256 colors.
	* The lighter the image, the smoother the system will run.
	* It can have any name as long as the extension is .png (Short names are recommended).
	* The name of the backgrounds will not be reflected in the settings, it will only be assigned a number.
	* To change the background you must enter the RETROLauncher settings, change the background and save the settings.

Animated Background Requirements:
	* It must be an image in .png format
	* The image must have a transparency mask otherwise it will not be displayed.
	* Resolutions can be of various sizes, although the recommended resolution is 640x480.
	* The maximum tested resolutions are those with a 280-pixel difference between height and width for 
	  PAL format (760x480 and 480x760) and a 460-pixel difference for NTSC format (940x480 and 480x940).
	  If these differences are exceeded, the program will fail.
	  Ideally, images should have a maximum difference of 280 pixels between height and width to be compatible 
	  with both PAL and NTSC.
	* It is recommended to use 8-bit png images with 256 colors.
	* The lighter the image, the smoother the system will run.

	For sprite animations:
	* For the image to be detected as an animation, it must include the "_ANI" nomenclature at the end of the name.
	Example: If the image is called "Background.png," it should be renamed by adding "_ANI" to the end of the name.
		This will result in "Background_ANI.png."
	* By default the number of columns and rows into which the image is divided is 4x4 giving a total of 16 animations, 
	  the number of columns and rows can be configured in the RETROLauncher settings menu, although the fastest way to 
	  automate this task is by adding to the name of the image the number of columns and rows into which the animation 
	  frames should be divided.
	Example: If the image is called "Fondo_ANI.png" and contains four animations, we rename it by adding the number 
		of columns and rows separated by an "x" just before "_ANI" (the first number corresponds to the columns 
		and the second to the rows).
		It should look like "Fondo 2x2_ANI.png". This way, RETROLauncher will automatically use that setting.
		If you're unsure of the number of columns and rows, simply rename the image with "_ANI" to configure it 
		from the RETROLauncher menu. It will ask if you want to rename the image so that it's configured correctly 
		for the next load.
	* The name of the backgrounds will not be reflected in the settings, it will only be assigned a number.
	* To change the background you must enter the RETROLauncher settings, change the background and save the settings.

	For layered animations:
	* For the image to be detected as an animation, it must include the "_LAY" suffix at the end of the name.
	Example: If the image is named "Background.png", it must be renamed by adding "_LAY" to the end.
		This will result in "Background_LAY.png".
	* All images will be divided into four layers, each assigned a number that determines its position on the screen.
		- The top left corner will be layer 1 (this layer will be in front).
		- The top right corner will be layer 2 (this layer will be in the background).
		- The bottom left corner will be layer 3 (this layer will be between layer 2 and layer 4).
		- The bottom right corner will be layer 4 (this layer will be in front of layer 3 and behind layer 1).
	* The position of the layers may vary in some configurations to achieve certain effects.
	* The dimensions of each layer will be automatically adjusted according to the image resolution.
	* If the image does not contain any configuration parameters, it will be assigned the default (static) settings.
		To add configuration parameters to the image, simply append "_LAY" to the end of the image name to configure it 
		from the RETROLauncher menu. You will be asked if you want to rename the image so that it is automatically 
		configured the next time it is loaded.
	* The configuration parameters are 8 alphanumeric characters (case-sensitive) located after the name and next 
		to "_LAY.png". Each of these alphanumeric characters represents a setting for the layer's animation. 
		They can be configured manually using a settings table, but it is recommended to use RETROLauncher itself 
		to make these changes.
	Example file name with configuration: "BACKGROUND_14101101_LAY.png"
		"_LAY" handles the image as a layered animation, and "_14101101" handles the layered animation settings.
		* The underscore character "_" after the name and before the configuration is required.
	* Background names will not be reflected in the configuration; they will only be assigned a number.
	* To change the background, you must access the RETROLauncher settings, change the background, and save the configuration.

Supported extensions: .png
